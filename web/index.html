macOS menu-bar plugin · SwiftBar

See which Claude Code session needs you.

The session that needs you is never the one in focus. Run five agents at once and never lose one — every session's status lives in your menu bar, glance-able, where you're already looking. Finished, working, stalled, ignored.

The smallest possible answer to “which agent needs me right now?” — and the best tool there is for running Claude Code in parallel.

    What it shows

    Everything answers one question — which agent needs me right now? — without pulling focus. And nearly everything here is highly customizable: ~29 config knobs, so it bends to your workflow, not the other way around.

    📊

    Menu-bar counters

    At a glance, no labels: how many sessions are working, freshly finished, or in follow-up. Dims when nothing's urgent.

    🗂️

    Urgency-sorted dropdown

    Every session active in the last 3h, sorted active → fresh → acked → stale. Click a row to jump to it in your editor.

    🗃️

    Session groups · new

    File sessions into groups in the Claude Code sidebar and the menu mirrors them — either the group name prefixing each row, or one folded entry per group whose header counts the live states inside. Read-only: grouping stays in the IDE.

    ❯

    Terminal sessions · new

    A session started in a shell is marked ❯, and its row raises the terminal tab that owns it — Terminal.app or iTerm2 by tty, then tmux, then screen, then claude --resume. No more resuming the same transcript twice.

    ⏳

    Subscription usage · new

    Your 5-hour and weekly windows as two bars under Statistics — yellow past 60%, red past 85%. Read straight from Claude Code's own get_usage: no inference, no quota spent, nothing left running.

    🔔

    Audible nudges · most-loved

    Chime + a spoken line via macOS say + a click-to-jump banner when a session finishes, stalls, or sits unread. It speaks what the session did and which one needs you — every phrase and the voice yours to set. See below.

    🤖

    Subagent rollup

    Sessions spawning Task subagents grow a 🤖×N badge with a live per-agent breakdown.

    ⚠️

    Context warnings

    Past 80% context the row shows ⚠ {pct}% (red past 90%) — a glance flags who's near auto-compact.

    ⎇

    Branch & worktree cues

    Rows flag a shared-folder collision (⎇), an isolated worktree checkout (ⓦ), and a blocked one reads waiting {duration} — so you see where work lands, not just that it's running.

    🌙

    Quiet hours & keep-awake

    Pause notifications on a schedule; caffeinate -i wrapper (off / auto / always) keeps the Mac up while agents run.

    🏷️

    Per-row submenu

    Remind (re-speak its last summary), Mark as read, Forget, Delete, Reveal in Finder — plus git branch, model chip, context %, and last tool_use on hover.

    🧰

    Tools submenu

    Bulk acknowledge/forget, today's activity (turns, tokens, by model), a Banner-and-voice / Banner-only toggle, and a jump to your config.

    📐

    Compact mode

    Crowded bar on a notched MacBook? "compact": true drops the icon and swaps 🟡🟢🔵 for narrow ANSI bullets ●2 ●1 ●3 — saves ~30px.

    🪶

    Stateless & light

    No daemon, no IPC. A Python script rebuilds the menu from disk every 5s. macOS stdlib only — nothing to keep running.

    ⚙️

    Highly customizable

    ~29 config knobs: phrases, voice, sounds, quiet hours, thresholds, the menu-bar icon, fresh/ack windows, compact mode, editor. Defaults work — change only what you want.

    most-mentioned feature

    Hear what a session did — and which one needs you.

    When a session finishes, stalls on a permission prompt, or sits unread, your Mac says it out loud — not just a chime, but a one-line summary of what it did and, for a blocked session, its name, so with five agents running you know by ear which to open without ⌘-tabbing. The summary comes from the *-- Name - Summary* line your replies end with. And the thing people keep calling out: every spoken phrase is yours to change.

    • 🟢 On finish — speaks the summary of what the session just did (no marker → a random notify_phrases line)
    • 🟡 On a permission prompt — names the blocked session + what it was doing, after a notify_wait_phrases line
    • ⏰ Idle nudge — a finished session you never opened is re-announced on a doubling schedule (20 → 40 → 80 min) with its own notify_idle_phrases
    • 🔁 Remind — any row's submenu re-speaks its last summary on demand, even under Banner only
    • 🔇 One-click Banner only in Tools → Notifications mutes speech + chime, keeps the banner
    • 🗣️ Any macOS voice via notify_voice; multi-part lines land as separate beats with a short pause between them

    Your name, inside jokes, a movie line, your dog's name — whatever makes you look up. The same marker can also retitle the menu rows (opt-in).

    (your browser blocks speech — it works fine in macOS say)
    config.json 
    {
  "notify_phrases": ["It is done, my liege", "Touch grass, I got this"],
  "notify_wait_phrases": ["I need an adult", "Halt — human required"],
  "notify_idle_phrases": ["Still here — still unread"],
  "notify_voice": "Samantha",
  "notify_threshold_sec": 30
}

    subagents

    A long Task won't lie to you.

    When a session fans out into Task subagents, the row grows a live 🤖×N badge — and the parent stays 🟡 working for as long as any subagent is in flight, so a 10-minute fan-out never drifts into a misleading 🟢 finished.

    • 🤖 Live count of in-flight subagents on the parent row
    • 🧾 Submenu lists each one — description, model chip, current tool, runtime
    • 🟡 Parent holds working until the last subagent returns
    🟡 Refactor authentication middleware 🤖×3 working
    • ↳Audit token validation paths sonnet-4-6 Grep · 1m04s
    • ↳Rewrite middleware tests opus-4-8 Edit · 0m41s
    • ↳Check callers across repo sonnet-4-6 Bash · 0m12s

    Install

    Homebrew. Idempotent — safe to re-run.

    step 1

    Install

    brew install --cask swiftbar
brew install terminal-notifier
brew install alexey-krylov/claude-agents-bar/claude-agents-bar
    step 2

    Wire it up

    claude-agents-bar setup

    Symlinks the plugin, registers the Claude Code hook, and merges hook entries into settings.json (with a timestamped backup).

    step 3

    Verify

    claude-agents-bar doctor

    Checks jq + python3 + SwiftBar.app, hook registration, sidecar freshness, and your editor app.

    terminal-notifier is optional — the menu-bar UI works without it, but banners + chime won't fire. No Homebrew? There's a git-clone path in the repo.

    How it works

    A Python script polls every 5 seconds. It reads the JSONL transcripts Claude Code already writes (for titles and cwd) plus a small sidecar TSV that a Claude Code hook updates on every session event — SessionStart, PreToolUse, Stop, and friends.

    No daemon, no IPC. The plugin is stateless and rebuilds the menu from disk on every tick. Without the hook it still runs, but every session reads as idle — the state TSV is what distinguishes working / waiting from idle.
